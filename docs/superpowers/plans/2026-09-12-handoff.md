## 6. Non-obvious invariants (reeducation — read before editing)

1. **`TlAnchorModel::$incrementing = false`** is load-bearing. Surrogate-PK rows (messages/updates/stories/channel_participants) leave `getKey()` **null/0 on sqlite**; tests must compare `account_id`/per-account counts, **never** `getKey()`. (Two test rewrites this session hit `assertSame(0, 0)` failures.)
2. **`tf_updates` is an append-only event log** (BIGSERIAL PK, spec §3.6): each `ingest()` appends one row; entity tables are upsert-stable. Re-ingest test asserts `N+1` updates rows, entity count unchanged.
3. **Only classified ctors persist.** Ephemeral nodes (`peerUser`, `messageMediaEmpty`, `messageEntity*`, `chatPhotoEmpty`) ride inside parent `tl_data` JSONB — never child rows (spec §4.1). Unknown/uncategorized ctors are dropped silently; a root without `_` throws `InvalidArgumentException`.
4. **Canonical peer longs**: `from_id`/`peer_id` stored as `PeerIdTool::userLong()/chatLong()/channelLong()` — NOT raw ids. `EntityAggregator::resolvePeer()` decodes via `PeerIdTool::decode()`.
5. **Global-ID vs surrogate PKs**: users/chats/channels/docs/photos/sticker_sets/wallpapers → PK `(id, account_id)` native id (2 rows per tenant for same Telegram entity); messages/dialogs/updates/stories/channel_participants → surrogate `id` + unique-scope constraint `(peer_id, message_id, account_id)` etc.
6. **Mix of two model generations**: `src/Schema/Generated/Models/Tf*` (pre-domain, still referenced by tests like `SubscriptionsTest`, `BindingsTest`, realtime listener, peer resolution docs) and `generated/Models/Tl*` (new domain). Both extend `TlAnchorModel`. Do not delete Tf* — tests use them as anchors.
7. **Zero-regex rule** (`preg_*` banned outside `src/Laravel/*`, `src/Schema/*`, `src/Bot/*`) — enforced by phpstan disallowed calls; do not add regex in `src/Teleframe/*`.
8. **`composer.lock` gitignored**; generated artifacts carry `@generated` — regenerate via `php bin/regenerate` / `teleframe:regenerate [--ship]`, never hand-edit.
